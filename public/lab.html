Welcome

Websites that can think, look things up and act.

A chatbot can only talk. An AI agent can also use your website's backend: it checks the database, books a table or tracks an order, then explains the result in plain language. Today you will see how that works and build one yourself.

Same question, two systems

"How much is the Chicken Biryani, and is my order 1022 on the way?"

Plain chatbot

No access to data

It only predicts likely text, so it guesses: a made-up price and a generic delivery time. This is called a hallucination.

AI agent

Uses the backend
LLM

The brain

Reads text and decides what to say or which tool to use. It cannot touch your database by itself.

Tools

The hands

Functions on your backend such as search_menu(). Each one has a name, a description and typed parameters.

Loop

Think, act, observe

The LLM calls a tool, reads the result, and repeats until it can answer. There is a step limit so it cannot run forever.

Backend

The boss

Holds the API key, runs the tools, validates inputs and decides what the agent is allowed to do.

        Module 5 · Security
        
Guardrail Arena

        
Attackers will type anything into your chat box. Pick an attack, switch defences on or off, and see what gets through. The goal is to stop all four attacks using only defences that are enforced in code.

      

      

        

          

          

            
Defences

            

          

        

        

          

          

            
Scoreboard

            

            
Soft defences live in the prompt or in word filters, and a rephrased attack can slip past them. Hard defences are rules in your backend code that the LLM cannot talk its way around.
